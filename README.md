# Dice Game

A two-player dice rolling game built with vanilla JavaScript. Players take turns rolling a die and the first to reach 20 points wins.

## How It Works

- Players alternate turns rolling a single die
- Each roll adds to that player's cumulative score
- The first player to reach 20 or more wins
- Click **Reset Game** to start over

## Tech Stack

- HTML, CSS, JavaScript

## How to Run

Open `index.html` in any web browser.
